# Project Screenshots & Images

Place your project image files in this folder (`public/projects/`).

Example files:
- `hash-identifier.png` -> referenced as `/projects/hash-identifier.png` or `public/projects/hash-identifier.png`
- `originai.png` -> referenced as `/projects/originai.png` or `public/projects/originai.png`
- `shulkerbox.png` -> referenced as `/projects/shulkerbox.png` or `public/projects/shulkerbox.png`

Recommended dimensions: 16:9 ratio (e.g., 1280x720 or 1920x1080) in PNG, JPG, or WebP.
